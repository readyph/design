# Memory

<Canvas of={Stories.Topics} />

## Purpose
What Leda knows about the business, and what she is still waiting to be told. Memory has three tabs: **Topics**, **Blocked questions** and **Customer requests**. A topic opens as its own page, and **Try it** runs a question against what Leda knows, as a modal.

## What is here
- Topics: `Topics`, `Grid`, `Search`, `SearchNoMatch`, `CompanyFolder`, `FilterOff`, `TopicPage`, `TopicDataSource`.
- Other tabs: `BlockedQuestions`, `CustomerRequests`. Overlay: `TryIt`.
- States: `Loading`, `ErrorState`, `Empty`, `Full`, `ReadOnly`.
- Phone: `PhoneFolders`, `PhoneRequests`, `PhoneTopics`.

## Shell
Runs in the real `PlatformShell` through the shared `PortalFrame`. The parts it composes are under Components / Portal: Topic library, Topic document, Blocked questions and Try it.
