TopicLibrary (RDY-287, C27, new): what customers' Leda knows, as a list (default) or a grid. Toolbar with search (200ms debounce, matches marked with an escaped matcher, Esc clears), Turn all on / off, New topic, business filter (Select), filters with counts (SegmentedControl; a Select on narrow containers) and a list / grid toggle. List = ruled square `List` rows (title link, two-line paragraph, folder, source, lock icon named "off by default", Switch); grid = flat tiles on `--raised`, 6px radius, no shadow. States: search matches, empty folder, no match, empty filter, read only, loading, error. Emit-only: `onToggle(topic, next)`, `onToggleAll(next)`, `onNew`, `onOpen`, `onQueryChange`, `onFilterChange`, `onBusinessChange`, `onLayoutChange`; the page filters `topics`, saves, asks before a bulk change and shows `toast.undo`. One j / k / Enter cursor shared by list and grid (`shortcuts`), never `/`. Props: `topics[{id,title,lines,source,sourceKind,folder,locked,lockNote,on,href}]`, `counts`, `filter`, `businesses`, `business`, `folderLabel`, `query`, `layout`, `allOn`, `readOnly`, `readOnlyNote`, `loading`, `error`, `onRetry`, `emptyHeadingLevel`. Also exports `useTopicLayout()` (localStorage `rph-mem-layout` in try/catch, read after mount) and `topicMatcher()`.
